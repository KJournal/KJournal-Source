# KJournal SideStore Source

SideStore app source for [KJournal](https://kjournal.github.io/KJournal-Source/).

## Usage

Add this source in SideStore:

```
https://kjournal.github.io/KJournal-Source/index.json
```

## Structure

- `index.json` — Source manifest (apps list)
- `_config.yml` — GitHub Pages configuration
- `404.html` — Redirect page
